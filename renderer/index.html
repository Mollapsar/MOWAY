    保存 Client ID

    桌面 PKCE 流程不使用 Client Secret。

PRIVACY

安全边界

01无密码接触

应用不会读取、传输或保存 EVE 密码和浏览器 Cookie。

02本机加密

刷新令牌经 Windows 安全存储加密，访问令牌仅驻留内存。

03无云同步

角色绑定和保存路线只存放在本机应用数据目录。

04可随时撤销

可在本程序移除角色，也可在 EVE 官方网站撤销授权。
