============================================================
一、软件功能
============================================================

MOWAY 是面向 Windows 的 EVE Online 第三方桌面路线规划工具。

核心特色：MOWAY 可以把优化后的路线批量写入多个已选择且在线的角色，
并把路径点精确保留到 NPC 空间站或玩家建筑级别。即使多个停靠点位于同一星系，
程序也不会在优化后把它们合并成一个星系点，而会分别写入各自的建筑 ID。
这解决了普通星系级路线规划无法保留同星系多个具体空间站或建筑的问题。

主要功能：

1. 在游戏外规划多段航线。
2. 联想搜索太阳系、NPC 空间站和角色可见的玩家建筑。
3. 将实际空间站或玩家建筑作为路径点，不会只写入所在星系。
4. 自动优化停靠顺序，以总星门跳数最少为目标。
5. 固定起点，并可选择是否固定终点。
6. 为所有已勾选且当前在线的绑定角色写入同一条路线。
7. 使用自定义文件夹整理绑定角色，为角色添加备注，并拖动调整顺序。
8. 使用自定义文件夹归类常用路线，拖动调整顺序，并可重命名路线和文件夹。
9. 导入或导出路线库文件，用于与其他用户分享路线或在电脑故障后快速恢复。
10. 在路线规划器中直接拖动途经点调整顺序，起点和终点保持固定。
11. 支持深色和白底主题，并记住主题选择。
12. 支持中文与英文 UI 切换，并记住语言选择。

自动优化推荐不超过 10 个节点，最多支持 15 个节点。
接近 15 个不同星系时需要查询较多 ESI 路线，请耐心等待。

同一星系中的不同空间站仍然是不同停靠点。它们之间按 0 个星门跳跃计算，
但写入游戏时会分别使用各自的空间站 ID，不会合并成星系路径点。
因此，优化目标是星系之间的总跳数，不会根据同一星系内的跃迁距离判断建筑先后。

UI 语言只影响按钮、说明、提示和错误文字。通过 ESI 取得的星系、空间站、
玩家建筑和角色名称不会翻译，始终按 EVE 返回的原名显示。

============================================================
二、运行方法
============================================================

推荐使用快速启动文件夹版：

1. 解压 MOWAY-V0.9527-fast-folder.zip。
2. 打开解压后的 MOWAY-V0.9527 文件夹。
3. 双击 MOWAY.exe。

不要只把文件夹版的 MOWAY.exe 单独复制出去，它需要同目录内的 DLL、
语言文件和 resources 文件夹。

单文件便携版可以直接运行，但每次启动都要临时解压，因此通常更慢。

系统要求：64 位 Windows 10 或 Windows 11，并能访问 EVE SSO 和 ESI。

界面右上角的“EN / 中文”按钮可以切换 UI 语言；选择会保存到本机。

============================================================
三、申请和配置 EVE SSO
============================================================

打开：
https://developers.eveonline.com/applications

创建 Authentication & API Access 应用。

回调地址必须逐字填写：
http://127.0.0.1:17890/callback

添加四项权限：

esi-location.read_online.v1
esi-ui.write_waypoint.v1
esi-search.search_structures.v1
esi-universe.read_structures.v1

保存后复制公开的 Client ID，并粘贴到 MOWAY 的“设置与安全”。

桌面 PKCE 登录不需要 Client Secret。不要把 Client Secret 填入 MOWAY，
也不要把 Client Secret、令牌或本机数据文件发给其他人。

127.0.0.1 是固定的本机回环地址，不是公网 IP；更换网络不会导致它变化。

============================================================
四、绑定和选择角色
============================================================

1. 打开“导航角色”。
2. 点击“绑定角色”。
3. 在系统浏览器打开的 EVE 官方页面登录、选择角色并授权。
4. 浏览器提示完成后返回 MOWAY。
5. 每个角色需要分别授权一次。
6. 用“参与导航”开关选择需要接收路线的角色。
7. 可以新建角色文件夹，把角色拖入文件夹并自由调整顺序。
8. 点击角色旁的铅笔按钮可以添加、修改或清除本机备注。

删除角色文件夹不会删除角色授权；其中的角色会移到“未归类角色”。
角色文件夹、顺序和备注只保存在本机 navigator-data.json 中，不会包含在路线库导出文件中。

登录只发生在系统浏览器的 EVE 官方 SSO 页面，MOWAY 没有密码输入框。

============================================================
五、规划和优化路线
============================================================

1. 打开“路线规划”。
2. 输入至少 3 个字符。
3. 从联想结果中选择星系、NPC 空间站或玩家建筑。
4. 添加需要的途经点。
5. 如需手动调整顺序，拖动途经点左侧的编号；起点和终点不会被拖动。
6. 选择最短、更安全或更危险路线。
7. 如需自动重排，勾选“自动优化停靠顺序”。
8. 起点始终固定；按需要选择是否固定终点。
9. 点击“计算航线”，检查顺序、总跳数和节省跳数。

修改或拖动途经点后，之前的计算结果会自动清除，需要重新计算后才能写入，
以避免误用旧路线。

超过 15 个节点时必须关闭自动优化或减少节点。
关闭优化后，可以按手动顺序规划更多节点。

路线偏好和优化结果不能识别实时营地、战争、泡泡或敌对势力，
请在写入前自行检查路线是否符合实际航行需要。

============================================================
六、写入游戏
============================================================

有两种写入方式：

仅写入规划停靠点：
只写入你选择的空间站、建筑、星系或途经点，ESI 请求较少。

逐跳锁定完整路线：
将计算结果中的每一跳依次写入，ESI 请求较多，长路线需要等待。

确认路线后点击“写入已选在线角色”。

程序只处理已勾选并且当前在线的角色；离线角色自动跳过，
单个角色失败不会阻止其他角色继续处理。

写入新路线会清除该角色原有的自动导航路径点，请先确认选择的角色和路线。

============================================================
七、保存与分享
============================================================

计算完成后点击“保存路线”，可以输入名称并选择保存到哪个文件夹。

在“已保存路线”页面可以：

- 新建、重命名或删除路线文件夹；
- 拖动路线调整顺序，或将路线移动到其他文件夹；
- 重命名、载入、直接写入或删除路线；
- 导出完整路线库；
- 导入其他用户分享的路线库或自己的备份。

导出的 .moway-routes.json 文件只包含路线、路线文件夹和排序，不包含角色授权、
角色文件夹、角色备注、刷新令牌、访问令牌、Client ID 或联系方式。可以把该文件分享给其他用户。

导入采用合并方式。相同路线 ID 会更新，不会反复生成副本。玩家建筑仍要求
接收文件的用户角色在游戏中拥有相应访问权限。

分享给朋友时，推荐发送：

MOWAY-V0.9527-fast-folder.zip
可选：公开的 Client ID

Client ID 可以共用，但每个人仍需在 EVE 官方页面授权自己的角色。

不要分享：

Client Secret
navigator-data.json
AppData 中的 moway 目录
访问令牌或刷新令牌
自己已经绑定角色后的程序数据副本

============================================================
八、常见问题
============================================================

1. 启动较慢

单文件版需要临时解压。建议使用完整解压后的快速文件夹版。

2. Windows 提示未知发布者

当前版本没有商业代码签名。请从可信渠道获取，并核对 SHA-256。

3. 没有联想结果

确认输入至少 3 个字符、已经绑定角色，并授予全部四项权限。
玩家建筑必须对用于搜索的角色可见。

4. 角色没有收到路线

确认角色已勾选“参与导航”、角色当前在线、授权仍然有效，
并点击“刷新在线状态”。

5. 授权后无法返回

确认回调地址为 http://127.0.0.1:17890/callback，端口 17890 没有被占用，
并检查防火墙、代理或安全软件是否拦截本机回环连接。

6. 出现“已拒绝来自非 MOWAY 主界面的请求”

请完全退出旧版 MOWAY，在任务管理器确认没有旧的 MOWAY.exe，
然后重新解压并启动最新 V0.9527，不要覆盖正在运行的旧目录。
