============================================================
一、MOWAY 接触不到什么
============================================================

MOWAY 没有 EVE 密码输入框。
账号和密码只在系统默认浏览器的 EVE 官方 SSO 页面中输入。

当前申请的四项权限不能通过 ESI 读取：

- EVE 账号密码；
- 钱包、资产、邮件、联系人、合同、技能和市场订单；
- 舰船实时位置；
- 其他没有授权给 MOWAY 的角色数据。

当前权限也不能通过 ESI 转账、交易、发邮件、操作市场、驾驶舰船或启动自动驾驶。

但是，如果整台电脑、浏览器或 Windows 账号已经被木马控制，攻击者可能绕过
MOWAY 直接窃取其他数据；此时 MOWAY 的权限限制不能保护整台电脑。

============================================================
二、使用了哪些安全措施
============================================================

- 使用系统浏览器打开 EVE 官方 SSO；
- 使用 Authorization Code + PKCE，不需要 Client Secret；
- 回调只监听本机 127.0.0.1；
- 校验 OAuth state、PKCE、JWT 签名、签发方、受众、有效期、角色和权限；
- 只申请实现当前功能所需的四项 ESI 权限；
- 刷新令牌通过 Electron safeStorage 使用 Windows 本机保护机制加密；
- 访问令牌只保存在程序内存中；
- 界面启用 CSP、上下文隔离、进程沙箱和导航限制；
- 拒绝摄像头、麦克风、定位等无关权限；
- 主进程只接受当前 MOWAY 本地页面发出的功能调用；
- 不包含作者服务器、广告、统计、遥测或云同步；
- V0.9527 使用发布时仍受支持的 Electron 44.7.2，并启用 ASAR 完整性校验。

这些措施只能降低风险，不能证明程序绝对安全。

============================================================
三、本机会产生什么文件
============================================================

主要数据目录：

%APPDATA%\moway

最重要的文件：

%APPDATA%\moway\navigator-data.json

它可能包含：

- Client ID、User-Agent 联系方式、回调地址、主题和 UI 语言；
- 角色名、角色 ID、角色文件夹、本机备注、排列顺序、授权范围、角色选择和最近在线检查状态；
- 保存路线、地点 ID、规划偏好和优化结果；
- 经 Windows 本机安全存储加密后的刷新令牌。

除了 navigator-data.json，Electron/Chromium 还可能产生 Cache、Code Cache、
GPUCache、Network、Local Storage、Session Storage、Preferences、Local State、
Shared Dictionary、Crashpad 等缓存和状态文件。

访问令牌、授权码、OAuth state 和 PKCE 校验值只在运行期间位于内存中，
MOWAY 不会主动把它们另存成日志文件。

只有在用户主动点击“导出路线库”后，程序才会在用户选择的位置创建
*.moway-routes.json 文件。该文件只包含路线、路线文件夹、排列顺序、地点 ID、
规划偏好和优化结果；不包含角色绑定、角色文件夹、角色备注、访问令牌、刷新令牌、
Client ID 或联系方式。
它仍可能暴露物流路线、集结点、常用空间站和玩家建筑名称，分享前请自行判断。

如果程序崩溃，Windows 还可能在以下目录产生 MOWAY 的 .dmp 转储：

%LOCALAPPDATA%\CrashDumps

单文件便携版运行时还会在 %TEMP% 中临时解压程序，正常退出后通常自动清理。

============================================================
四、数据被别人拿到会发生什么
============================================================

1. 只拿到 navigator-data.json

对方可以直接看到角色关联、角色文件夹和备注、常用路线、空间站、玩家建筑、最近状态、
Client ID 和填写的联系方式。这些信息可能暴露小号、常驻地、物流路线、
集结点或活动规律。

刷新令牌不是明文。仅把文件复制到另一台电脑或另一个 Windows 用户下，
通常无法直接解密；但“已加密”不等于绝对安全。

2. 对方能在相同 Windows 用户环境中运行程序

这是更严重的情况。Windows safeStorage 主要防其他用户或离线复制，
不能可靠抵御同一用户空间中的木马。攻击者可能调用本机解密能力取得刷新令牌。

3. 刷新令牌或运行中的访问令牌被窃取

攻击者可能在当前四项授权范围内：

- 查看角色是否在线；
- 搜索角色可见的玩家建筑；
- 读取角色有权查看的建筑名称和所在星系；
- 清空、添加或篡改游戏内自动导航路径点。

刷新令牌可以继续换取短期访问令牌，直到官方授权被撤销或令牌失效。
只关闭程序、删除 EXE 或在 MOWAY 界面移除角色，不能替代官网撤销授权。

4. 被修改的假版本

当前 EXE 没有商业代码签名，Windows 可能显示“未知发布者”。
攻击者可以冒充作者发送修改后的程序。只从可信渠道获取，并核对 SHA-256。

SHA-256 只能证明文件与发布者给出的那一份一致；如果校验值也来自不可信渠道，
它不能证明文件安全。

5. 对方只拿到导出的路线库文件

对方不能仅凭该文件取得角色授权或控制 MOWAY 中绑定的角色，但可以看到其中的
路线、文件夹名称、地点和排序信息。路线库文件适合备份或分享路线，不应被当成
完全不含隐私的公开文件。

============================================================
五、功能本身的风险
============================================================

- 写入新路线会清除角色原有的自动导航路径点；
- 选错角色或地点可能把路线写给不应接收的角色；
- 自动优化只比较 ESI 路线跳数，不理解实时营地、泡泡、战争和敌对势力；
- “更安全”不等于实际航行一定安全；
- 接近 15 个节点会产生较多 ESI 请求，可能变慢或遇到限流；
- ESI、SSO、网络、系统根证书或接口规则变化可能导致失败；
- 没有自动更新功能，如果作者停止维护，旧版风险会随时间增加。

发布前的依赖公告检查发现一项 electron-builder 构建链中的中等风险告警，
位于不会打入最终应用的 sprintf-js，且当时上游没有修复版本。
它不属于用户运行时代码，但仍说明依赖检查不能等同于绝对安全认证。

============================================================
六、怀疑泄露时怎么办
============================================================

1. 在可信设备上登录 EVE 官方账号管理页面。
2. 撤销 MOWAY 或对应 Client ID 的全部第三方应用授权。
3. 完全退出 MOWAY。
4. 删除 %APPDATA%\moway。
5. 对 Windows 做完整恶意软件扫描，并检查远程控制软件和浏览器扩展。
6. 没有排除木马前不要重新授权角色。
7. 如果密码、邮箱或验证码也可能泄露，请修改 EVE 与邮箱密码、检查双重验证，
   并联系 EVE 官方支持。
8. 把已保存的路线、角色关联和建筑信息视为对方已经知晓，必要时改变行动计划。

撤销官方授权是让失窃刷新令牌失效的关键步骤。

============================================================
七、如何安全清理本机数据
============================================================

1. 完全退出 MOWAY，在任务管理器确认没有 MOWAY.exe。
2. 如需终止令牌，先在 EVE 官方账号页面撤销第三方应用授权。
3. 按 Win+R，输入 %APPDATA% 后回车。
4. 删除整个 moway 文件夹。
5. 删除下载的 EXE、ZIP、解压文件夹、说明文档和自行创建的快捷方式。
6. 按需要清空回收站。
7. 如程序曾崩溃，打开 %LOCALAPPDATA%\CrashDumps，只删除名称明确包含
   MOWAY 的 .dmp 文件。
8. 如需清理登录痕迹，在实际用于授权的系统浏览器中删除
   login.eveonline.com / eveonline.com 的 Cookie、站点数据、缓存和历史。
   这可能同时退出浏览器中的其他 EVE 官方页面。
9. 单文件版异常退出后，可重启 Windows，再通过“设置 → 系统 → 存储 →
   临时文件”进行常规清理。不要凭猜测批量删除其他程序的临时目录。
10. 如果自己创建的 EVE Developer 应用以后完全不用，可以在 EVE Developers
    删除它；如果 Client ID 正与朋友共用，删除后他们也会失效。

完成这些步骤后，可以清除普通用户能够安全处理的主要 MOWAY 文件、配置、
路线和令牌数据。

但是普通应用无法保证抹除 Windows、浏览器、网络设备、安全软件或 CCP 服务器
各自保存的审计记录。Prefetch、Defender/SmartScreen、事件日志、DNS、路由器日志
和磁盘恢复痕迹属于系统或取证范围。不建议为了所谓“绝对无痕”手工破坏注册表、
系统日志或安全记录。

============================================================
八、分享时不要发什么
============================================================

可以分享：

- 官方发布的程序压缩包；
- 与可信渠道一致的 SHA-256；
- 公开的 Client ID（如果决定共用）。

不要分享：

- Client Secret；
- navigator-data.json；
- %APPDATA%\moway 整个目录；
- 访问令牌或刷新令牌；
- 已经绑定自己角色的程序数据副本；
- 包含私人邮箱或 Discord 的配置文件。
